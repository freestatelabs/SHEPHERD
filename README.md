# SHEPHERD
Open-source mechanical FEA that *just works*.

This project is in the planning/prototyping phase and has no functionality currently. Looking for collaborators!

## Elevator Pitch
A finite element analysis solver written for simplicity and maintainability. It should showcase good high performance computing software engineering techniques to preserve this knowledge for the next generation of engineers developing these codes. In particular, clear code and documentation are paramount.

## Project Goals:
* High-performance structural and thermal calculations for the design engineer
* Easily deploy on Windows, Linux, and MacOS - all required libraries are included in this repository (zero-dependency)
* Highly parallelized operations, use every processor core available
* Focused feature set; written with eye towards simplicity and maintainability
* Thoroughly documented code and theory manual with validation examples
* Interoperability with Calculix input files
* Static, modal, transient, & nonlinear analysis types all supported
